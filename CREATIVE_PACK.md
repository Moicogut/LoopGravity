# CREATIVE_PACK.md: LoopGravity Copywriting & Campaign System

## 1. Narrativa Principal (Storytelling: Marco PAS)

* **Problema (Problem):** Los asistentes de código actuales solo autocompletan fragmentos o generan código desconectado en sandboxes efímeros. Para construir una aplicación real, el desarrollador pierde horas redactando prompts manuales, corrigiendo dependencias rotas, creando carpetas de configuración y lidiando con código no tipado o inseguro.
* **Agitación (Agitate):** Cada nuevo proyecto se convierte en una pesadilla de configuración manual de agentes, context-switching interminable y deuda técnica acumulada. Mientras tanto, tu tiempo para salir al mercado (Time-to-Market) se desvanece.
* **Solución (Solution):** **LoopGravity** introduce el motor de bucles autónomos de ciclo cerrado para Google Antigravity. Defines la visión y la arquitectura una sola vez; el motor orquesta escuadrones de agentes especializados (`investigador`, `branding`, `creativo`, `app-developer`, `auditor`) que construyen, prueban, auditan y auto-corrigen tu aplicación hasta cumplir con el 100% de tus estándares de producción.
